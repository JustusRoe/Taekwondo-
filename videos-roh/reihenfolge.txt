# Reihenfolge der Einschrittkampf-Videos (Hanbon Kyorugi)
#
# Eine Datei je Zeile, von oben nach unten. Zeile 1 wird Nr. 1 im
# Mitgliederbereich. Leere Zeilen und alles hinter # wird übersprungen.
# Relative Pfade gelten ab diesem Ordner – die Rohaufnahmen liegen im
# Repository, deshalb zeigen die Zeilen nach ../assets/video/.
#
# Danach:
#   werkzeuge/video-aufbereiten.sh --liste videos-roh/reihenfolge.txt \
#       assets/video hanbon-kyorugi
#   php werkzeuge/videodaten-erzeugen.php
#
# Die Reihenfolge folgt der Dateinummer der Kamera. Die creation_time
# taugt dafür nicht: Bei den klein geschriebenen .mov steht dort der
# Zeitpunkt des Exports (Blöcke um 11:39, 11:50 und 12:02), nicht der
# der Aufnahme. Bei den groß geschriebenen .MOV stimmt sie und steigt
# mit der Dateinummer – deshalb ist die Nummer der richtige Maßstab.
#
# IMG_1258, IMG_1265 und IMG_1280 sind nachträglich beschnitten
# (1338x752, 1624x914, 1646x926 statt 1920x1080). Sie zeigen deshalb
# einen anderen Bildausschnitt als die übrigen.
#
# Noch offen: Die Techniknamen stehen in assets/js/videodaten.js als
# "Einschrittkampf 1" bis "Einschrittkampf 13". Wer die Reihe kennt,
# trägt dort die richtigen Bezeichnungen und Gürtelgrade ein; ein
# weiterer Lauf von videodaten-erzeugen.php überschreibt sie nicht.
